# Sand Bucket

Личная браузерная игра по мотивам основной механики Sand Loop: цветной песок, вёдра на конвейере и один собственный уровень. Без рекламы, магазина, аккаунтов и сервера.

## Запуск

Node.js 22.12+ (CI использует Node.js 24), npm.

```sh
npm ci
npm run dev
```

Открыть адрес `/sand-bucket/`, который напечатает Vite. Для проверки production-сборки:

```sh
npm run check
npm run build
npm run preview
```

Dev-сервер доступен в локальной сети для проверки с телефона. Service Worker работает только в production-сборке на HTTPS или localhost; обычный HTTP по IP компьютера не проверяет офлайн-режим.

## Правила прототипа

- Нажать переднее ведро одной из трёх очередей, чтобы отправить его на ленту. Остальные вёдра очереди открываются по порядку.
- На ленте пять мест. Перед запуском следующего ведра вход должен освободиться.
- Ведро собирает только свой цвет с нижнего края картинки при проходе под ней. Песок осыпается вниз и по диагонали; вместимость — точное количество песчинок.
- Полное ведро исчезает. Неполное продолжает двигаться по кругу.
- Победа — собран весь песок. Проигрыш — нет возможности добавить нужное ведро и полный оборот ленты не изменил ни сбор, ни положение песка. Само заполнение ленты не означает поражение.
- Таймера, платных мест, бустеров и жизней нет. При смене вкладки игра становится на паузу. Перезапуск и выход в меню начинают новый заход; сохраняется только отметка прохождения.

Это собственная реализация основного цикла, а не подтверждённая покадровая копия оригинала. Публичные руководства расходятся в деталях; точное соответствие исходной игре не заявляется.

## Устройство

TypeScript + Vite + PixiJS (WebGL). Сетка 128 × 112, фиксированный шаг 60 Гц; отрисовка песка одной обновляемой текстурой. Размер интерфейса не меняет правила симуляции. Статические HTML-кнопки доступны с клавиатуры, цвета вёдер подписаны.

- `src/game.ts`: состояние, уровень, симуляция и правила, без браузерных зависимостей.
- `src/renderer.ts`: текстура песка, лента, вёдра и декоративные потоки.
- `src/main.ts`: меню, управление, пауза, результат и сохранение.

Тесты проверяют сохранение песка, соответствие цветов, вместимость, запуск, доказанный тупик, победу, чистый перезапуск, неверные данные, полное решение и проигрыш на поставляемом уровне.

## GitHub Pages и офлайн

Workflow проверяет типы, тесты и сборку. Только `main` публикуется в GitHub Pages; ветка разработки и PR проходят проверки без деплоя. Слияние требует отдельного одобрения владельца.

Адрес после публикации: https://lemonb.github.io/sand-bucket/ . База путей `/sand-bucket/` задана в `vite.config.ts`.

Service Worker заранее кеширует сборку и все локальные ресурсы. После сообщения «Можно играть без интернета» страницу можно открывать офлайн. На iPhone: Safari → Поделиться → На экран «Домой». Обновление применяется после закрытия всех окон игры и нового открытия; текущая партия не прерывается обновлением. Очистка данных браузера удалит кеш и локальную отметку прохождения.

## Проверка на устройстве перед релизом

- iPhone 13+: проверить плавность во время сбора пятью вёдрами, нагрев и управление пальцем. Цель — 60 кадров/с; desktop-проверка не подтверждает производительность телефона.
- Проверить безопасные отступы, портретный режим, возврат после блокировки экрана и перезапуск.
- После первого полного открытия отключить интернет, закрыть игру и открыть снова с главного экрана.
- Пройти уровень, перезагрузить страницу и проверить сохранённую отметку.

Звук, генератор и дополнительные уровни в первую версию не входят.
